# PePe Mobile — projet personnel C113

Site en ligne : https://peperonity89.github.io/c113-projet-toska-perparim/

## 1. 🎨 Présentation du projet

### Concept
- Thème choisi : PePe Mobile, un opérateur de téléphone mobile en Suisse (inventé).
- Public cible : Les Suisses qui veulent un abonnement simple et pas cher.
- Objectifs du site : montrer les abonnements, les comparer et pouvoir nous contacter.

### Fonctionnalités prévues
- Navigation : un menu de 4 pages.
- Sections principales : Accueil, Mobile, À propos, Contact.
- Contenus proposés : 2 abonnements (Swiss à 5.- et Swiss Max à 15.-), un tableau pour les comparer, une image du réseau, le téléphone et les horaires du service client.

### Choix de design
- Palette de couleurs :
  - Fond : `#000000` (noir) : le logo ressort bien.
  - Texte : `#FFFFFF` (blanc).
  - Cartes : `#732A4A` (framboise foncé).
  - Boutons : `#B1435B` (framboise).
  - Liens et titres : `#DA574D` (corail).
  - J'ai vérifié que chaque texte se lit bien sur son fond.
- Lien vers palette générée : …
- Typographies :
  - Titres et texte : Verdana, parce qu'elle est très facile à lire.
  - Verdana appartient à Microsoft : je n'ai pas le droit de la copier dans /fonts. Le site utilise celle de l'ordinateur.
